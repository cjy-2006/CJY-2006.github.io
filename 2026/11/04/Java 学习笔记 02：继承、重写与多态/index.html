2. 方法重写（Override）

子类可以重新实现父类允许被重写的方法。

@Override 是注解，用来让编译器检查是否真的重写了方法。

它不是重写行为发生的必要条件，但建议保留。

例如将 speak() 错写成 speek()，有 @Override 时编译器会指出问题。

重写不是修改父类原有的方法，而是让子类提供自己的版本。
