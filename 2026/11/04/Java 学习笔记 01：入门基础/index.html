Java 学习笔记 01：入门基础

学习阶段：Java 基础与面向对象入门
目标：理解 Java 程序的基本结构、类、对象、方法和封装。

1. Java 程序如何运行

基本过程：

  • JDK：Java 开发工具包，包含编译、运行和其他开发工具。
  • JRE：Java 运行环境，提供运行 Java 程序所需的环境。
  • JVM：Java 虚拟机，负责执行字节码。

2. Java 程序的入口

  • class：定义类。
  • public：访问修饰符。
  • static：表示方法属于类，不需要先创建对象即可调用。
  • void：方法不返回值。
  • main：这里采用传统的 Java 程序入口方法。
  • String[] args：命令行参数数组。

注意：Java 对大小写敏感；若声明 public class Hello，源文件通常必须命名为 Hello.java。

3. 基本数据类型和引用类型

Java 有八种基本数据类型：

类型 示例
byte byte a = 10;
short short a = 100;
int int age = 20;
long long n = 100L;
float float x = 1.5f;
double double x = 1.5;
char char c = 'A';
boolean boolean ok = true;

除此之外，类、数组、接口等涉及引用类型。

  • int 是基本类型。
  • String 是类。
  • 数组是对象，因此 int[] 是引用类型。

Java 不是“所有数据都是对象”。

类用于定义对象的数据与行为。

  • Student：类。
  • new Student()：创建对象。
  • s1、s2：引用变量。
  • 两次 new 创建两个不同对象。

5. 构造方法与 this

构造方法的特点：

  • 名称与类名相同。
  • 没有返回类型。
  • 使用 new 创建对象时会调用相应的构造方法。

this 表示当前对象。

左边是当前对象的属性，右边是构造方法接收的参数。

7. 封装与访问控制

private 限制其他类直接访问字段。

通过公开方法，可以控制外部能够读取或修改什么数据。

常见访问修饰符：

  • public：公开访问。
  • protected：同包及满足继承规则的子类可访问。
  • 无修饰符：包内访问。
  • private：仅在声明它的类内部直接访问。

封装不等于机械地给所有属性生成 Getter 和 Setter，而是控制对象的内部状态如何被使用。

8. 多文件与分层

你之前的学生成绩作业可以采用三个类：

  • Student：保存学生数据。
  • StudentProcess：处理成绩计算和输出。
  • Main：创建对象，组织程序执行。

Java 编译器能够根据类名、包、类路径和编译配置查找其他类，不要求把所有代码写在同一个文件里。
