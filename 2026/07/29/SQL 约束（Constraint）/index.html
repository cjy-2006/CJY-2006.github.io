SQL 约束（Constraint）

一、概念

SQL 约束（Constraint）是用于限制数据库表中数据规则的一种机制。

通过约束可以保证数据的：

  • 完整性（Integrity）
  • 一致性（Consistency）
  • 正确性（Accuracy）

约束通常在创建表（CREATE TABLE）或修改表（ALTER TABLE）时定义。

二、SQL 六大约束类型

SQL 常见约束分为：

1. PRIMARY KEY（主键约束）

定义

主键约束用于唯一标识表中的每一条记录。

一个表中的每一行数据都必须拥有唯一的标识。

特点

  • 一个表只能有一个主键
  • 主键值不能重复
  • 主键值不能为空（NULL）
  • 通常作为其他表引用的目标
