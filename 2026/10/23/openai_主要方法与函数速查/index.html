openai_主要方法与函数速查

openai Python 库：主要方法、参数与作用

适合初学者查阅；核对日期：2026-10-23。这是常用接口导览，不是全部 API 清单。

1. 先看调用结构

  • OpenAI：客户端类；OpenAI(...) 创建一个客户端对象。
  • client：自己起的变量名，用来保存客户端。
  • chat.completions：客户端下面的对话接口。
  • create()：向服务端发请求，创建一条回复。
  • response：保存返回结果的变量名，并不是库里的函数。

同样叫 create()，放在不同对象下作用也不同：images.generate() 生成图片，files.create() 上传文件。完整路径比最后一个方法名更重要。

2. 客户端与通用方法

名称 作用 何时用
OpenAI(...) 创建同步客户端，调用时等待结果 入门、普通脚本
AsyncOpenAI(...) 创建异步客户端，配合 await 异步服务、同时处理多个任务
client.with_options(...) 派生带不同请求配置的客户端 临时修改超时、重试次数
client.close() 关闭连接资源 程序不再调用时；也可使用 with OpenAI(...) as client: 自动关闭

构造客户端的常用参数：

参数 意思
api_key 服务商密钥；不应直接写进提交到 Git 的代码
base_url 服务商接口根地址；DeepSeek 用 https://api.deepseek.com；OpenAI 官方通常省略
timeout 请求超时设置，例如 60.0 秒
max_retries 部分暂时性错误的自动重试次数；0 表示关闭自动重试

3. 文本和对话：最常用

方法 作用 备注
client.chat.completions.create(...) 根据消息列表生成回答 当前 DeepSeek 项目优先掌握
client.responses.create(...) OpenAI 的统一生成接口，可处理支持的文本、图片及工具任务 不能假定 DeepSeek 支持
client.responses.parse(...) 按指定的数据结构解析输出 结构化结果，常配合 Pydantic
client.chat.completions.parse(...) Chat Completions 的结构化输出辅助方法 服务端、模型必须支持相关格式
client.responses.stream(...) 用上下文管理器消费 Responses 流式事件 与普通完整返回的读取方式不同

chat.completions.create() 常见参数

参数 作用
model 选择服务商支持的模型
messages 输入消息列表，包括历史问答
stream False 等完整结果；True 分段接收
temperature 调整采样随机性；可用范围、是否支持由模型决定
top_p 另一种采样控制参数，初学时通常不必同时调它和 temperature
max_completion_tokens OpenAI Chat 中限制生成 token 数；兼容服务商可能使用不同参数，例如 max_tokens，应查其文档
tools 告诉模型有哪些可调用工具；模型返回调用请求，实际函数由你的程序执行
tool_choice 控制是否、如何选择工具
response_format 请求 JSON 等输出格式；需模型和服务端支持
extra_body 传递 SDK 未直接列出的服务商扩展字段，不是任意参数都有效

当前项目最小示例

deepseek_key.txt 与脚本放一起，只存密钥；将它加入 .gitignore。模型名称采用核对当天 DeepSeek 官方示例。

返回值的常用属性和方法

写法 意思
response.choices[0].message.content Chat Completions 第一条回答的文本
response.choices[0].message.tool_calls 模型提出的工具调用请求，可能为空
response.choices[0].finish_reason 回答为什么结束，例如正常结束或达到长度限制
response.usage token 用量信息，某些情况下可能为空
response.output_text Responses 接口汇总的文本；不是 Chat Completions 的通用属性
response.model_dump() 将返回对象转成 Python 字典
response.model_dump_json() 将返回对象转成 JSON 字符串

content、usage 是属性，不加括号；model_dump() 是方法，要加括号。

流式输出

流式读取 delta.content，不是完整回复的 message.content。对话记忆需要自己维护 messages，客户端不会自动记住每次调用。

4. 图片、语音、向量等主要方法

以下是 OpenAI SDK 的接口目录。安装了库，不等于 DeepSeek 提供这些服务。 使用前需要对应服务商的接口、模型和权限。

方法 作用 典型用途
client.images.generate(...) 按文字描述生成图片 插图、海报
client.images.edit(...) 结合输入图片和描述进行编辑 改背景、修改画面
client.audio.transcriptions.create(...) 将音频转成文字 机器人听取用户讲话
client.audio.translations.create(...) 将支持的音频翻译成英文文字 不是任意目标语言翻译接口
client.audio.speech.create(...) 将文字转成语音 机器人播报回答
client.embeddings.create(...) 把文本变成数值向量 语义检索、相似度匹配；不会直接生成聊天回答
client.moderations.create(...) 检测内容所属的风险类别 内容审核；结果仍需业务逻辑处理
client.models.list() 查询当前服务端返回的模型列表 查看可用模型
client.models.retrieve(model_id) 查询指定模型信息 查看模型元信息，不代表能查到所有能力和价格

看图通常是向支持视觉的对话或 Responses 模型传入图片内容，不是调用 images.generate()。普通字符串 "C:\\照片.jpg" 不会自动上传图片。

5. 文件和批处理：需要时再学

方法 作用
client.files.create(...) 上传文件，需指定用途；并不自动让模型读取或记住它
client.files.list() 列出文件
client.files.retrieve(file_id) 查询文件信息
client.files.content(file_id) 获取文件内容
client.files.delete(file_id) 删除文件
client.batches.create(...) 提交受支持接口的批量任务，异步处理
client.batches.retrieve(batch_id) 查询批处理状态
client.batches.cancel(batch_id) 请求取消批处理
client.fine_tuning.jobs.create(...) 为支持微调的模型创建训练任务，入门阶段可跳过

常见命名规律：create 创建，list 列表查询，retrieve 查询一个，delete 删除，cancel 取消。不是每个资源都有全部这些方法。

6. 错误处理用到的类

这些是异常类，不是发送请求的方法。

类 常见含义
openai.AuthenticationError 身份验证失败，通常是密钥问题
openai.BadRequestError 参数或请求格式不正确
openai.RateLimitError 触发限流，具体原因看服务端返回信息
openai.APIConnectionError 网络连接失败
openai.APITimeoutError 请求超时
openai.APIStatusError 服务端返回失败状态；可读取 status_code

7. 哪些东西不属于 openai 库？

名称 来自哪里、做什么
load_dotenv() python-dotenv 包：把 .env 配置加载到环境变量，不负责加密
os.getenv() Python 标准库：读取环境变量
Path.read_text() Python 标准库 pathlib：读取文本文件
print() Python 内置函数：打印内容
json.loads() Python 标准库：将 JSON 字符串解析成 Python 数据

对你现在的机器人项目，先掌握：OpenAI() → chat.completions.create() → message.content，再学 stream=True。语音识别和语音合成可由其他服务商提供，不必和对话模型来自同一家。
